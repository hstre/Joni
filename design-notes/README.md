(Core-Rebuild, Method-Trial-Messprotokolle, Trial-Event-Projektor, SQLite-Migration,

`docs/layer9.html`, `docs/data.json`).

Sie sind hierher verschoben, **nicht gelöscht**: „Ohne Geschichte ist man verurteilt, Fehler
wieder zu machen." Sie werden von keinem Code gelesen (nur in Docstrings referenziert, die jetzt
hierher zeigen) und nicht mehr publiziert. Die für die Nachfolge relevante
`docs/PERSONA_SUCCESSION.md` blieb bewusst in `docs/` (das Mandat verweist auf diesen Pfad).
