Recent literature observes that embodied agent architectures are typically hand-designed, with researchers relying on intuition rather than systematic experimentation to determine how information is stored and observations processed. Mainstream VLA models for robotic manipulation assume a Markovian process, using only the current observation to predict actions, which leads to difficulties with long-horizon, temporally dependent tasks. Existing memory-augmented VLA methods either expand the observation window or retrieve history from an external memory bank.
