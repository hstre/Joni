Self-attention enables each token to retrieve information from the full context, but its quadratic cost has spurred the development of linear attention architectures. A saliency-based visual attention model combines multiscale features into a topographical saliency map, which a dynamical neural network uses to select attended locations in order of decreasing saliency. Experimentally, orienting of attention is investigated by having subjects commit attention to a non-fixated position in visual space.
